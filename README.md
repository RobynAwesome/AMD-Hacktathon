# GOA Creative Commerce

**Imagine freely. Ground every part. Surface unmet demand.**

Built for the **AMD ACT III — Reinvent Commerce** track.

---

## 1. Core Principles

1. **Create without buying:** People can describe, compose, remix, and save an outfit without commercial commitment. Creation is **never** treated as purchase intent (`is_purchase_intent = False`).
2. **The person is the author:** AI decomposes a natural-language brief into parts (`DRESS_OR_SUIT`, `SHOES`, `OUTER_LAYER`, `ACCESSORY`), ranks candidates, and explains verified results. The customer can swap any part (`SelectedBy.CUSTOMER`).
3. **Honest numbers & deterministic verification:** Python rules (`goa-verify-1.0.0`) check catalogue existence, part category, size availability, stock quantity, delivery lead time against the event date, known price (integer ZAR cents), and total budget. Any `FAIL` or `UNKNOWN` fails closed.
4. **Two-sided commercial loop:**
   - **Available (`AVAILABLE`):** Verified items can be sent in a customer-authorized demo quote enquiry (`customer_authorized = True`) with a server-issued `ValidationReceipt` (SHA-256 `receipt_digest`).
   - **Needs customer input (`NEEDS_CUSTOMER_INPUT`):** Missing customer sizes or dates are surfaced back to the customer (*"Add your size to check availability"*) and are **never** logged as merchant supply gaps.
   - **Not on offer yet (`NOT_ON_OFFER_YET`):** Genuine supply gaps are shown honestly to the customer and logged as `DemandGap` records for the Merchant Gap View.

## 3. Quickstart

### Prerequisites
- Python 3.12+ and [`uv`](https://docs.astral.sh/uv/)

### Install & Verify
```bash
uv sync
uv run python scripts/export_schemas.py --check
uv run pytest
```

### Run the Frozen 20-Brief Evaluation
```bash
uv run python scripts/run_evaluation.py
```
Writes `evidence/eval/evaluation_v1_results.json` after verifying the LF-normalised SHA-256 of `data/eval/briefs_v1.json` (`b52ec5e8ec858e39581b49ed7c2802f630721c03ab68eeefed12d89a63cd2baf`).

### Launch the Web Application
```bash
uv run uvicorn goa.app:app --reload --port 8000
```
Open `http://127.0.0.1:8000` to explore:
- **Tab 1 — Customer Creation Studio:** Describe an outfit, inspect `ADD YOUR SIZE` vs `AVAILABLE` vs `NOT ON OFFER YET`, remix alternatives, save without buying, or authorize a demo merchant quote enquiry.
- **Tab 2 — Merchant Inbox & Gap View:** Inspect the data-driven unmet-demand table (*"5 of 20 briefs requested a green linen jacket that was not available"*) and the fictional merchant demo quote inbox.

## 4. Optional AMD Token Factory / Gemma Configuration

By default, if no LLM credentials are set in the environment, GOA runs with its deterministic rule-based parser (`InterpretationSource.RULE_BASED_FALLBACK`) and reports `provider_configured = false` on `/api/v1/health`.

To enable live OpenAI-compatible AMD Token Factory / Gemma inference:
```bash
export GOA_LLM_BASE_URL="https://<your-amd-endpoint>/v1"
export GOA_LLM_API_KEY="<your-api-key>"
export GOA_LLM_MODEL="google/gemma-3-27b-it"
```
(Aliases `TOKEN_FACTORY_BASE_URL`, `TOKEN_FACTORY_API_KEY`, `RADEON_API_KEY`, and `GEMMA_MODEL` are also supported.)

## 5. Synthetic Data, Original Artwork & Demo Disclaimers

- **Fictional Merchants & Catalogue:** All 3 merchants (*Fynbos Atelier*, *Karoo & Cobble*, *Table Bay Tailoring*) and all 48 products in `data/` are synthetic demo records (`is_fictional = true`).
- **Original Vector Illustrations:** All 48 SVG files in `frontend/catalogue/` are original algorithmic vector illustrations generated by `scripts/seed_catalogue.py` (`image_source = "ORIGINAL_GENERATED_SVG"`, `image_licence = "PROJECT_ORIGINAL_ARTWORK_LICENCE_PENDING_OWNER"`).
- **Simulated Commercial Action:** Quote enquiries (`QuoteEnquiry`) are delivered to an in-app demo merchant inbox (`is_demo = true`). No real orders, reservations, or payments are placed.
